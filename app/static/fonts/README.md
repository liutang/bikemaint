# Vendored fonts

Self-hosted so the app makes no third-party requests at runtime. Latin subset, variable weight, WOFF2.

- `inter-latin-wght.woff2`: Inter (Rasmus Andersson), SIL Open Font License 1.1, from `@fontsource-variable/inter@5.1.0`.
- `space-grotesk-latin-wght.woff2`: Space Grotesk (Florian Karsten), SIL Open Font License 1.1, from `@fontsource-variable/space-grotesk@5.1.0`.
