# Research: Unified Bike Screen and Simpler Parts

1. **Bike identity**: store `year`, `make`, `model` and derive `name` at write time (list pages, maintenance pages and tests already read `bike.name`). Legacy bikes have NULL year/make/model and keep `name`. Edit rule for legacy bikes: all three blank keeps the name, all three filled replaces it, a mix is a field error. Dropping `catalog_id` uses `ALTER TABLE ... DROP COLUMN` (SQLite 3.35+, present in the Python 3.13 images).
2. **Simplified kinds**: `ComponentKind.offered: bool`. `COMPONENT_TYPES` (offered, in display order) drives all UI lists and the create boundary; `ALL_COMPONENT_TYPES` includes legacy kinds. Placement rules keep legacy kinds' parents and add legacy parents for offered kinds where old data exists (tire also on rim). The service still creates any known kind (internal/legacy callers and tests); the HTTP create/palette boundary accepts only offered kinds.
3. **Scope-based builder**: `build_view(root)` where root is `bike:ID` or `component:ID` (including storage components). Scope = root plus its descendants. Add/move/delete requests carry `root`; the service verifies the moved part is in storage or in scope and the destination is in scope or storage. Fragment responses re-render the same root. Bike roots behave exactly as the 004 builder.
4. **Breadcrumbs**: `builder_service.breadcrumbs(root)` returns `[(label, url)]`: Garage; the bike (or Storage); ancestors; the current part (no link). Rendered as `<nav aria-label="Breadcrumb"><ol>` with `aria-current="page"` on the last item.
5. **Actions follow the part**: a `part_actions` partial renders Edit, Maintenance history, Add schedule, Adjust mileage, plus Garage and Trash for parts, and Pair with Strava / Delete for bikes.
6. **Delete in place**: `POST /builder/delete` returns the fragment, or the fragment with a confirmation panel when the service raises `ConfirmationRequiredError`; deleting the root part returns `HX-Redirect` to the level above (303 without HTMX).
7. **Removed**: build page (`GET /bikes/{id}/build` redirects), Build/Add component buttons, `/components/{id}` Move form (the Move-to select inside the tree replaces it). `/components/new` stays for storage parts created from the garage page.
